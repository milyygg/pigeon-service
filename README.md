# Pigeon Service

Сайт-визитка частного мастера по ремонту телефонов, ноутбуков и компьютеров в Санкт-Петербурге. Услуги, цены, примеры ремонта, отзывы и контакты. Клиентский проект.

## Как скачать и открыть у себя

1. Нажмите зелёную кнопку **Code** вверху страницы репозитория, затем **Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `index.html` в браузере. Сборка не требуется.

## Что внутри

- `index.html` - страница, адаптивные стили и интерактивные элементы
- `assets/` - фотографии ремонта и изображения

Технологии: HTML, CSS, JavaScript.
